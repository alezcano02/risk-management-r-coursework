# Risk management in R (Universidad EIA, 2024)

Scripts of the Risk Management course:

| Script | Topic |
|---|---|
| `01_var_tesla.Rmd` | VaR at 97% of Tesla with 400 days of prices, with the interpretation |
| `02_capm.R` | CAPM: betas of AAPL, MSFT, GOOGL, AMZN and TSLA against SPY |
| `03_ahp_candidate_selection.R` | AHP to choose between 3 candidates with 4 criteria |
| `04_electre_iii.R` | ELECTRE III with preference, indifference and veto thresholds (group work) |
| `05_fuzzy_logic_selection.R` | Fuzzy logic system to score candidates |
| `06_arima_gold.R` | ARIMA on the gold ETF (GLD) |
| `07_logit_classification.R` | Logistic regression with caret on the Pima diabetes data |
| `08_credit_risk_class_imbalance.Rmd` | Oversampling and undersampling (ROSE) on credit data |

`data/` has the inputs of the AHP and ELECTRE exercises and the Pima diabetes data. The credit data of script 08 was course material and is not included. Run the scripts from the root of the repository.
